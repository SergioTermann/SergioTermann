## 关于我

北京航空航天大学自动化学院博士研究生，主要研究方向为**大模型 Agent、多智能体强化学习与具身智能**。作为一家初创科技公司的合伙人和 AI 负责人，负责从技术路线、系统架构、模型训练到工程部署与项目交付的完整流程。

近期工作聚焦于基于 **Planner-Executor、混合 RAG、知识图谱、SFT、Function Calling 与反馈闭环**的生产级 Agent 系统，同时具备 Isaac Sim、大规模分布式强化学习、GPU 集群和大模型本地化部署经验。
